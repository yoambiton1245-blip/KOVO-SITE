# KOVO – אתר מטבחים בהתאמה אישית

האתר של KOVO: עמוד אחד בעברית, עם גלריה, מעצב מטבח, טופס פניות וכפתורי וואטסאפ.
האתר מתפרסם ב־**Vercel**. כל שינוי ב־GitHub יוצר כתובת תצוגה מקדימה, ורק שינוי ב־`main` עולה לאתר האמיתי.

## מה יש בתיקייה
```
public/        האתר עצמו: עמודים, עיצוב, תמונות, סרטון, גופנים, קוד (בלי שלב בנייה)
  config/site.config.js   המקום היחיד לטלפון, וואטסאפ, אינסטגרם ומייל
  config/projects.js      רשימת התמונות בגלריה
  shared/                 רשימות שמשותפות לאתר ולשרת (סוגי פרויקטים, צבעים וחומרים)
api/leads.js   טופס "השאירו פרטים": שולח את הפנייה במייל (הפונקציה היחידה בשרת)
lib/           קוד לטופס: בדיקת שדות, ניקוי קלט, שליחת מייל, חסימת שליחות מאתרים אחרים
test/          בדיקות אוטומטיות (npm test)
tools/serve.mjs  הרצה מקומית של האתר לבדיקה (npm run preview)
vercel.json    הגדרות Vercel: תיקיית האתר, כותרות אבטחה, מטמון
```

"שמירה וקישור" במעצב המטבח לא שומר כלום בשרת: הבחירות נכתבות בתוך הקישור עצמו, כך שהוא נפתח בכל מכשיר.

## הגדרות שצריך פעם אחת ב־Vercel
**Settings > Environment Variables** (לא נכנסים לקוד ולא ל־GitHub):

| משתנה | מה זה |
|---|---|
| `SMTP_USER` | כתובת ה־Gmail ששולחת את הפניות: `Kovo.kitchen1@gmail.com` |
| `SMTP_PASS` | סיסמת אפליקציה של Gmail (16 תווים). לא הסיסמה הרגילה |
| `LEAD_EMAIL_TO` | לאן מגיעות הפניות: `Kovo.kitchen1@gmail.com` |

**Firewall**: כלל אחד שמגביל שליחות חוזרות של הטופס (`POST /api/leads`) מאותה כתובת.

אם המייל לא מוגדר או נכשל, הגולש מקבל הודעה לנסות שוב או לכתוב בוואטסאפ, כך שפנייה לא הולכת לאיבוד בשקט.

## עבודה שוטפת
- `npm install` – התקנה (פעם אחת).
- `npm test` – בדיקות.
- `npm run preview` – האתר על http://localhost:3000, כולל הטופס. מייל לא נשלח באמת (מודפס במסוף).
- החלפת תמונה, סרטון או גופן: לתת לקובץ החדש **שם חדש**. קבצים בתיקיית `assets` נשמרים בדפדפן של הגולש ליום אחד.
