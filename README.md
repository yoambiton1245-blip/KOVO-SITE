# KOVO – אתר מטבחים בהתאמה אישית

האתר של KOVO: עמוד אחד בעברית, עם גלריה, מעצב מטבח, טופס פניות וכפתורי וואטסאפ.
האתר מתפרסם ב־**Vercel**. כל שינוי ב־GitHub יוצר כתובת תצוגה מקדימה, ורק שינוי ב־`main` עולה לאתר האמיתי.

## מה יש בתיקייה
```
public/        האתר עצמו: עמודים, עיצוב, תמונות, סרטון, קוד (בלי שלב בנייה)
api/           פונקציות שרת ב־Vercel
  leads.js       טופס "השאירו פרטים": שולח את הפנייה במייל
  designs/       "שמירה וקישור" במעצב המטבח (שמירה ב־Vercel Blob)
lib/           קוד משותף לפונקציות: בדיקת שדות, ניקוי קלט, שליחת מייל
shared/        רשימות שמשותפות לאתר ולשרת (סוגי פרויקטים, צבעים וחומרים)
test/          בדיקות אוטומטיות לפונקציות (npm test)
tools/serve.mjs  הרצה מקומית של האתר לבדיקה (npm run preview)
vercel.json    הגדרות Vercel: תיקיית האתר, כותרות אבטחה, מטמון
netlify/, netlify.toml, public/_headers, public/_redirects
               שייכים לאתר הישן ב־Netlify. נשארים עד סיום המעבר, ו־Vercel מתעלם מהם (.vercelignore)
```

## הגדרות שצריך פעם אחת ב־Vercel
**Settings > Environment Variables** (לא נכנסים לקוד ולא ל־GitHub):

| משתנה | מה זה |
|---|---|
| `SMTP_USER` | כתובת ה־Gmail ששולחת את הפניות, למשל `Kovo.kitchen@gmail.com` |
| `SMTP_PASS` | סיסמת אפליקציה של Gmail (16 תווים). לא הסיסמה הרגילה |
| `LEAD_EMAIL_TO` | לאן מגיעות הפניות (ברירת מחדל: `SMTP_USER`) |

**Storage > Blob**: ליצור Blob store ולחבר לפרויקט (בשביל "שמירה וקישור"). Vercel מוסיף לבד את `BLOB_READ_WRITE_TOKEN`.

אם המייל לא מוגדר או נכשל, הגולש מקבל הודעה לנסות שוב או לכתוב בוואטסאפ, כך שפנייה לא הולכת לאיבוד בשקט.

## עבודה שוטפת
- `npm install` – התקנה (פעם אחת).
- `npm test` – בדיקות לפונקציות.
- `npm run preview` – האתר על http://localhost:3000, כולל הטופס והשמירה. מייל לא נשלח באמת (מודפס במסוף), ועיצובים נשמרים בזיכרון.
